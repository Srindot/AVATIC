# Literature survey

Papers on the same problem: finding and hitting balloons (or other aerial
targets) with a drone using a camera. Only the links are kept here; read
the papers on arXiv.

## Vision based Target Interception using Aerial Manipulation (2020)

Lima Agnel Tony, Shuvrangshu Jana, Aashay Bhise, Varun V P, Aruul Mozhi
Varman S, Vidyadhara B V, Mohitvishnu S Gadde, Debasish Ghose, Raghu
Krishnapuram. MBZIRC Symposium 2020.

- arXiv: [2009.13066](https://arxiv.org/abs/2009.13066)
  ([PDF](https://arxiv.org/pdf/2009.13066))
- **Why read it:** the MBZIRC 2020 Challenge 1 is almost this competition:
  UAVs explore, detect, approach and pop balloons at unknown places. It
  covers the whole chain, from detecting the balloons in the image to the
  guidance that closes in on one, on real hardware with ROS.

```bibtex
@article{Tony_2020,
  title={Vision based Target Interception using Aerial Manipulation},
  author={Lima Agnel Tony and Shuvrangshu Jana and Aashay Bhise and Varun V P and Aruul Mozhi Varman S and Vidyadhara B V and Mohitvishnu S Gadde and Debasish Ghose and Raghu Krishnapuram},
  journal={arXiv preprint arXiv:2009.13066},
  year={2020}
}
```

## Toward Increased Airspace Safety: Quadrotor Guidance for Targeting Aerial Objects (2021)

Anish Bhattacharya. Master's thesis, Carnegie Mellon University
(CMU-RI-TR-20-39).

- arXiv: [2107.01733](https://arxiv.org/abs/2107.01733)
  ([PDF](https://arxiv.org/pdf/2107.01733))
- **Why read it:** a quadrotor that targets semi-stationary and moving
  aerial objects with little prior knowledge of them.
  Useful for the guidance: how to turn a target seen in the camera into
  flight commands that close the distance.

```bibtex
}
```
